# Smart Checkout System

Інтелектуальна система автоматичного розпізнавання товарів та формування електронного чека з використанням YOLOv8 і методів комп’ютерного зору.

---

## Опис проєкту

Даний проєкт представляє систему автоматичного розпізнавання товарів у сфері роздрібної торгівлі. Система виконує детекцію товарів на зображенні, підрахунок їх кількості та автоматичне формування електронного чека із розрахунком загальної вартості покупки.

Для реалізації системи використовується модель **YOLOv8l**, навчена на наборі даних **RPC Dataset (Retail Product Checkout Dataset)**.

---

## Основні можливості

- автоматичне розпізнавання товарів;
- детекція об’єктів за допомогою YOLOv8l;
- підрахунок кількості товарів;
- автоматичне формування електронного чека;
- відображення результатів у графічному інтерфейсі;
- підтримка великої кількості категорій товарів;
- візуалізація обмежувальних рамок та результатів детекції.

## Навчання моделі

Навчання моделі включає:

- конвертацію анотацій COCO → YOLO;
- використання transfer learning;
- аугментацію зображень;
- mixed precision training (AMP);
- ранню зупинку (early stopping);
- підбір гіперпараметрів.

### Основні параметри навчання

| Параметр            | Значення |
| ------------------- | -------- |
| Модель              | YOLOv8l  |
| Кількість епох      | 120      |
| Розмір зображення   | 960×960  |
| Batch size          | 8        |
| AMP                 | True     |
| Mosaic augmentation | True     |
| Mixup augmentation  | True     |

## Результати

Навчена модель YOLOv8l досягла таких результатів:

- **mAP50:** 76.2%
- **Precision:** ~84%
- **Recall:** ~68%

Система демонструє стабільну роботу навіть у складних checkout-сценах із великою кількістю дрібних товарів та частковими перекриттями об’єктів.
